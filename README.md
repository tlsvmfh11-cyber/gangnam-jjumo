# 강남 쩜오 SEO 최적화 랜딩페이지

> 구글 1위를 목표로 한 초고급 SEO 최적화 랜딩페이지

## 🎯 프로젝트 정보

- **키워드**: 강남 쩜오
- **목표**: 구글 검색 1~5위 동시 독점
- **SEO 등급**: S등급 (575점 이상)

## 🚀 시작하기

### 설치
```bash
npm install
```

### 개발 서버
```bash
npm run dev
```
서버: http://localhost:3000

### 프로덕션 빌드
```bash
npm run build
npm run preview
```

## ✅ SEO 최적화 완료

- Core Web Vitals 최적화
- Schema.org 마크업 (FAQPage, LocalBusiness)
- 모바일 우선 반응형
- E-E-A-T 신뢰도 강화
- Lighthouse 95+ 목표
